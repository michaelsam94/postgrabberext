PostGrabber queue

Saved posts live in chrome.storage.local as JSON. Use the right-click submenu on Facebook to add posts, then load them into the composer one at a time (Facebook’s UI changes often—verify before publishing). Debugging: open DevTools (Console) on this page for queue actions; on the Facebook tab for composer automation. Lines are prefixed [PostGrabber …]. On Facebook, run postgrabberLogCopy() in the console to copy the last 200 log lines.
